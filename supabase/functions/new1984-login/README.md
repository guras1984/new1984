# New1984 ID login function

Deploy from this repository with `supabase functions deploy new1984-login` after linking the Supabase project. The project reference is `lubrwnbluclmpoxnkzul`. The Edge Function reads the built-in `SUPABASE_URL`, `SUPABASE_ANON_KEY`, and `SUPABASE_SERVICE_ROLE_KEY` variables. Never expose or put the service-role key in the browser.
